# Activating CODE X MART (no internet needed)

Activation needs no internet connection on the shop computer. You only need a phone to send and receive a code on WhatsApp, or to call.

## When the free trial has ended

1. Open CODE X MART and sign in as usual. The **activation screen** appears. Your shop data is safe: nothing has been deleted.
2. Click **Generate / View License Request Code**. A code like this appears, with the computer's Device ID:

   ```text
   CXMR-7K92X-4P6DQ-8W3HM-5R2XA-JN4TC-QB7EZ-2HM9S-VK8PL
   ```

3. Send this code to **Hamad Mansha, +92 348 6825408**:
   * click **Copy Request Code** and paste it into WhatsApp (on a computer with WhatsApp), or
   * take a photo of the screen with your phone and send it on WhatsApp, or
   * read it out on the phone.

   **Contact on WhatsApp** opens a chat when this computer has internet. Without internet, use the number on the screen.
4. You receive an **activation key**. It starts with `CXMA-` and has 34 groups of five characters, like this:

   ```text
   CXMA-2HM9S-VK8PL-QB7EZ-... (34 groups)
   ```

5. Type or paste it into **Activation key** and click **Activate License**.

That's all: CODE X MART opens normally. The key is checked on this computer, using a key built into CODE X MART.

## Typing the key

* Capital or small letters, spaces, dashes and line breaks do not matter.
* Codes never contain the characters **0, 1, I or O**. If you see something that looks like one of them, it is another character (for example 2, Q, J or D).
* Each group's last character is a check character. While you type, groups turn **green** when correct and **red** when a character in them is wrong, so you only need to recheck the red group.
* **Activate License** becomes available when all 34 groups are complete and correct.

## Activating early, renewing, upgrading

Any time during the trial, or to renew a license that is about to expire, go to **Settings → License**. The same request code and activation key boxes are there. A new key adds to the license already in place; the app always uses the best valid license (lifetime first, then the one that runs longest).

## Messages you may see

| Message | Meaning |
|---|---|
| Typing mistake in group N | A character in that group is wrong. Compare it with the key you received. |
| This is a request code, not an activation key | You typed the code you send, not the one you receive. |
| …issued for a different computer | The key was made for another computer's request code. Send *this* computer's request code. |
| …not genuine, or a character in it was changed | All typing checks passed, but the signature does not match. The key was changed, or it is not from the owner. |
| …not signed by the CODE X MART license key | The key comes from somewhere else, or it needs a newer version of CODE X MART. |
| This activation key expired on … | The license period has already ended. Ask for a new key. |
| This computer's date is earlier than the key's issue date | Correct the date and time in Windows settings, then try again. |

More help: [Troubleshooting](LICENSE_TROUBLESHOOTING.md).

## After activation

* The license stays valid after restarts, updates and reinstalls.
* Uninstalling with either choice ("keep" or "delete all my data") keeps the license on this computer.
* The license belongs to this computer. On a new computer, or after replacing the motherboard, send the new request code to the owner for a transfer ([Device binding](DEVICE_BINDING.md)).
